# spacefarers

Fiori Elements List Report and Object Page (OData V4, SAPUI5 1.152) for the `GalacticService` spacefarers. Generated with the SAP Fiori application generator; the UI annotations live in `annotations.cds` next to this file.

Run it from the project root as described in the [root README](../../README.md). `pnpm run watch-spacefarers` starts the server and opens the app.
