## spacefarers

Manage galactic spacefarers.

### Starting the app

From the project root, run `pnpm run watch` and open http://localhost:4004/galactic.spacefarers/index.html, or run `pnpm run watch-spacefarers`, which opens it for you. Log in with a mock user, for example `alice` / `alice`.

The OPA tests run in the browser at http://localhost:4004/galactic.spacefarers/test/integration/opaTests.qunit.html while the server is running.

#### Prerequisites

1. Active Node.js LTS version and pnpm (see https://nodejs.org).
